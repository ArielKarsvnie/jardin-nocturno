admin del jardín

Solo para el jardinero

Para editar desde acá, pegá tu token de GitHub. Queda guardado solo en este navegador.

¿Cómo consigo el token?
  1. Entrá a github.com/settings/personal-access-tokens/new.
  2. Token name: jardin-admin. Expiration: lo que quieras (por ejemplo, 1 año).
  3. Repository access: Only select repositories → jardin-nocturno.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copialo (empieza con github_pat_) y pegalo acá.
